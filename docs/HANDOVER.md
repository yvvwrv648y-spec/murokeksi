## 1. The game in one page

One Godot 4.7.2 game: every main region Kanto → Paldea plus Orre, the Ranger regions, Mystery Dungeon content, the Orange Islands, Hisui, and a final original island region (Sirena, binds last, never alluded to anywhere else). Pokémon and Moemon (the anime-girl variant set) playable at parity — identical data, one difficulty standard. Every trainer challenge fields 6 Pokémon at competitive standard: best natures/abilities/moves from the species' best sourced Smogon set, IV 31 unconditional, EV 510 budget (deterministic trim only; no invented spreads). Opponents level/evolve with the player; re-challenge via Vs. Seeker. Level caps by global badge count; EXP accrues past caps; no disobedience. Permadeath in story and co-op (VEXA simulations and rentals exempt). Official gimmicks only, per-progression unlocks, none in Kanto. Custom characters pick any two basic pre-evolutions (no Legendaries/Mythicals/uniques) at Oak, from species with follower AND battle animation bound+ready.

**Locked bind order:** Kanto → Johto → Kalos → Hoenn → Unova → Sinnoh → Orange → Hisui → Paldea → Orre → Ranger → Sirena.

**The single biggest honest gap in the project: boot and playthrough are UNVERIFIED.** No record shows the assembled game started and played end-to-end by anyone. The Windows executable is artifact-verified only (exists, right size/fingerprint). Every playability claim rests on headless test suites run piece-by-piece. Closing this is verification job #1 in the assembly prompt.
