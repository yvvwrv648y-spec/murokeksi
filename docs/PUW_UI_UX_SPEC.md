# PUW_UI_UX_SPEC.md
- **Status:** `SPECIFIED`
- **Design System:** Native Godot 4.7.2 container-based responsive UI (zero fixed-coordinate mobile overlap), safe-area aware for iPhone 17 Pro Max, uncluttered contextual HUD.
- **Opening Menu:** New Game, Continue, Load Game, Character Setup (11-step guided flow), Settings, Accessibility, Credits.
- **In-Game Menu:** Pokédex (PKDX + MDX), Party, Bag (11 categories, search/sort/filter/favourites), Trainer Profile, Map, Quest Log, Character Wardrobe, Pokémon Info, Settings, Save, Help.
